## Getting started
`whoami` - print effective user name
```
whoami
```
`pwd` - Print name of current/working directory. 
```
pwd
```
`ls` - List directory contents. Commonly used with `-l` to long list.
```
ls -l
```
`cd` - Change the directory. `cd` is procedeed with a directory name `cd /tmp/`. How do you know its a directory? when you run the command `ls -l /tmp/` 
```
cd
```
